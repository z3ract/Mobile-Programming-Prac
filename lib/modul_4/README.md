# Modul 04: Widget Flexible dan Expanded

## Deskripsi & Topik
Modul ini membahas teknik pembagian ruang layar secara proporsional dan adaptif menggunakan widget Flexible dan Expanded. Mahasiswa mempelajari cara kerja faktor pembagi ruang (flex), parameter fit: FlexFit.tight vs FlexFit.loose, serta pencegahan overflow pada berbagai dimensi layar.

---

## Struktur Berkas
```text
lib/modul_4/
├── praktikum/
│   ├── percobaan_1/
│   │   └── main.dart    # Percobaan 1: Penggunaan widget Flexible
│   └── percobaan_2/
│   │   └── main.dart    # Percobaan 2: Penggunaan widget Expanded
├── tugas/
│   └── main.dart        # Tugas mandiri kombinasi Flexible dan Expanded
└── README.md
```

## Panduan Menjalankan Program

Pastikan berada di direktori root proyek (master_repo):

### 1. Menjalankan Percobaan 1 (Flexible)
```bash
flutter run -t lib/modul_4/praktikum/percobaan_1/main.dart
```

### 2. Menjalankan Percobaan 2 (Expanded)
```bash
flutter run -t lib/modul_4/praktikum/percobaan_2/main.dart
```

### 3. Menjalankan Tugas Mandiri
```bash
flutter run -t lib/modul_4/tugas/main.dart
```
