# Modul 05: Widget SizedBox, Spacer, dan Card

## Deskripsi & Topik
Modul ini mempelajari penggunaan widget pembatas ruang dan wadah kartu pada antarmuka Flutter:
* SizedBox: Memberikan jarak bernilai tetap (fixed size) antara widget.
* Spacer: Mengambil sisa ruang kosong yang tersedia secara dinamis menggunakan sistem flex.
* Card: Menampilkan informasi dalam bentuk kartu persegi bersudut melengkung dengan efek elevasi bayangan (elevation).

## Panduan Menjalankan Program

Pastikan berada di direktori root proyek (master_repo):

### 1. Menjalankan Percobaan 1 (SizedBox)
```bash
flutter run -t lib/modul_5/praktikum/percobaan_1/main.dart
```

### 2. Menjalankan Percobaan 2 (Spacer)
```bash
flutter run -t lib/modul_5/praktikum/percobaan_2/main.dart
```

### 3. Menjalankan Percobaan 3 (Card)
```bash
flutter run -t lib/modul_5/praktikum/percobaan_3/main.dart
```

### 4. Menjalankan Tugas Mandiri
```bash
flutter run -t lib/modul_5/tugas/main.dart
```
