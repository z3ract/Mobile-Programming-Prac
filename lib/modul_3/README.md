# Modul 03: Pengaturan Layout Row dan Column di Flutter

## Deskripsi & Topik
Modul ini berfokus pada pemahaman dan pengimplementasian sistem tata letak (layout) dasar pada Flutter menggunakan widget Row dan Column. Mahasiswa mempelajari pengaturan sumbu utama (MainAxisAlignment) dan sumbu silang (CrossAxisAlignment) untuk menyusun elemen UI secara horizontal maupun vertikal.

---

## Struktur Berkas
```text
lib/modul_3/
├── praktikum/
│   └── main.dart        # Implementasi latihan tata letak Row dan Column
├── tugas/
│   └── main.dart        # Tugas mandiri penerapan layout responsif
└── README.md
```

---

## Panduan Menjalankan Program

Pastikan Anda berada di direktori root proyek (master_repo):

### 1. Menjalankan Kode Praktikum
```bash
flutter run -t lib/modul_3/praktikum/main.dart
```

### 2. Menjalankan Kode Tugas
```bash
flutter run -t lib/modul_3/tugas/main.dart
```

Atau pilih perangkat/browser target:
```bash
flutter run -t lib/modul_3/praktikum/main.dart -d chrome
```
